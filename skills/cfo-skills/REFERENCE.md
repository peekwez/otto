# Couqley Brand Guidelines - Quick Reference

## Color Palette Quick Reference

### Primary Colors

```
Cream/Beige Background: #F7F3E9 | RGB(247, 243, 233)
Couqley Red:           #CC3333 | RGB(204, 51, 51)
Gold/Tan Accent:       #BF9966 | RGB(191, 153, 102)
```

### Chart Colors

```
Bear Scenario:   #B42D2D | RGB(180, 45, 45)  - Dark Red
Base Scenario:   #D2B48C | RGB(210, 180, 140) - Tan
Target Scenario: #E4D2B4 | RGB(228, 210, 180) - Light Tan
```

## Typography Standards

### Font Hierarchy

- **Display Headers**: 36-48pt, Bold, Couqley Red or Gold
- **Section Headers**: 24-30pt, Bold, ALL CAPS
- **Subheaders**: 18-20pt, Bold
- **Body Text**: 11-12pt, Regular
- **Captions**: 9-10pt, Regular or Italic

## Logo Specifications

### Minimum Sizes

- Print: 1 inch width minimum
- Digital: 150px width minimum
- Small applications: 0.75 inch (use simplified version if available)

### Clear Space

- Maintain minimum clear space equal to the height of the letter "C" in "COUQLEY"
- No other elements should appear within this space

### Acceptable Uses

✓ Full logo with "FRENCH BISTRO" tagline on light backgrounds
✓ Centered on title/cover pages
✓ Top right corner on content pages
✓ Monochrome red version on cream background

### Unacceptable Uses

✗ Stretching or distorting the logo
✗ Changing colors outside brand palette
✗ Removing "FRENCH BISTRO" tagline
✗ Adding effects (shadows, gradients on logo itself)
✗ Low contrast backgrounds

## Financial Data Formatting

### Number Formatting Rules

- **Currency**: $1,935,292 (commas for thousands, no decimal unless cents)
- **Percentages**: 28% (whole numbers unless precision needed)
- **Large Numbers**: 10,274,730 (no abbreviations unless noted)
- **Decimals**: Two places for financial ratios (e.g., 1.25)

### Table Standards

```
Header Row: White text on Couqley Red background
Data Rows:  Black text on cream/white background
Alignment:  Right-align numbers, left-align labels
Borders:    Minimal lines, or gold accent borders
```

## Common Design Patterns

### Pattern 1: Side-by-Side Analysis

Use for comparing multiple scenarios or datasets:

- Two-column layout
- Gold border separating columns
- Consistent header treatment
- Aligned data presentations

### Pattern 2: Progressive Data Display

Use for year-over-year growth:

- Horizontal bar charts
- Left-aligned labels
- Brand color progression (Bear → Base → Target)
- Numerical values on bars

### Pattern 3: Hierarchical Information

Use for complex documents:

- Main header: Red background, white text
- Sub-headers: Red text on cream
- Body: Black text on cream
- Gold accent dividers between sections

## Accessibility Considerations

### Color Contrast Ratios

- Red (#CC3333) on Cream (#F7F3E9): 4.8:1 ✓ (WCAG AA compliant)
- White on Red: 6.2:1 ✓ (WCAG AA compliant)
- Black on Cream: 12.6:1 ✓ (WCAG AAA compliant)

### Text Readability

- Minimum font size: 11pt for body text
- Use bold for emphasis, not just color
- Ensure charts have both color and pattern differentiation
- Provide text alternatives for data visualizations

## Quality Assurance Checklist

### Visual Review

- [ ] Logo is correctly placed and sized
- [ ] All colors match brand specifications (hex codes verified)
- [ ] Typography is consistent throughout
- [ ] Borders and frames use curved-corner gold style
- [ ] White space is balanced and adequate

### Content Review

- [ ] All numbers formatted consistently

- [ ] Charts use correct brand colors

### Technical Review

- [ ] File format is correct (.pptx, .pdf, .docx)
- [ ] Images are high resolution (300 dpi minimum)
- [ ] Document properties/metadata complete
- [ ] File named according to convention
- [ ] Accessible to intended audience (permissions)

## Brand Don'ts

### Visual Don'ts

✗ Don't use gradients on the logo itself
✗ Don't use colors outside the brand palette
✗ Don't use script or overly decorative fonts for body text
✗ Don't crowd elements - maintain generous white space
✗ Don't use clipart or low-quality images

### Content Don'ts

✗ Don't be overly casual or use slang
✗ Don't overuse French terminology (keep it authentic but accessible)
✗ Don't make unsupported claims about financial performance
✗ Don't use inconsistent number formatting
✗ Don't mix different data visualization styles in one document

## Additional Notes

### Seasonal Variations

- Holiday materials may include subtle seasonal accents
- Maintain core brand colors as primary palette
- Add seasonal elements as secondary accents only

### Regional Adaptations

- If expanding to multiple locations, maintain consistent brand identity
- Allow minimal local customization while preserving core standards
- All materials must be approved by brand management

### Digital Applications

- Website should reflect brand color palette
- Social media graphics should include logo or brand colors
- Email signatures should use brand colors and logo
- Digital ads must follow same guidelines as print materials

---

**Remember**: When in doubt, prioritize elegance, clarity, and brand consistency. The Couqley brand represents sophisticated French bistro dining, and all materials should reflect this positioning.
